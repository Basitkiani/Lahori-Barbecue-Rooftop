# Lahori Barbecue Rooftop

A responsive, buildless restaurant website. Open index.html in a browser, or serve this directory with any static hosting provider. No installation or build is required.

## Editing
- Contact details and hours: site-config.js
- Menu, prices, text and imagery: index.html
- Layout and colours: styles.css
- Menu filters, gallery and reservation drafts: app.js

Dishes and photographs are illustrative. Address, phone, prices and hours are placeholders awaiting restaurant approval. Reservations prepare downloadable drafts only; nothing is sent or confirmed. Images and fonts load from Unsplash and Google Fonts.
